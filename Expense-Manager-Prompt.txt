Create an html, css and javascript app called expense-manager which is used for managing daily expenses and income transactions. Use the current workspace/folder to create necessary files. The requirements of the application are mentioned below:
1. On the top of the application create 3 cards - Income, Expense, Total Balance.
2. Each Card must display the amount respectively with different background color - Light red for expense, light green for income and light blue for total balance.
3. Below to the cards there should be a form with fields - Description, Amount, date of transaction, transaction type.
4. Next is the list of transactions which displays the transaction information with different background color. Use negative and positive sign for expense and income respectively. In each list item display the date with calendar icon.
5. Keep the look and feel of the application modern and elegant.
6. Add an option on the top of the application to switch the overall theme of the application to dark or light.
7. The overall interface must be in center screen position and must be responsive to display in different screen sizes.
8. Use only html, css and javascript to create this application and store the data in local storage of the browser.
9. Use font awesome icons for adding the icons in this application to make the application looks good.

Create a fastapi app to build a REST API to perform CRUD operations. The model fields are - description, amount, dateoftransaction and transactiontype. The app uses sqlite to save data in database. Enable cors from all origins and methods. Keep the code minimal.

Integrate the backend api in this app which is running on http://localhost:8000/transactions. Use fetch api for making an http call to the api. The model for the api is 
```
{
  "description": "string",
  "amount": 0,
  "dateoftransaction": "2026-11-02",
  "transactiontype": "income"
}
```
